Условия использования

Обновлено: 3 сентября 2026 г.

1. Назначение

Hermes Google Workspace — личное приложение для автоматизации рабочих процессов владельца (контент-таблицы, расписания, планирование) через Google Sheets, Drive, Docs и Calendar.

2. Пользователи

Приложение предназначено исключительно для владельца — Наиля Галиуллина. Предоставление доступа другим пользователям не предусмотрено.

3. Ограничения использования

  • Запрещено использовать приложение для обработки данных, на которые у владельца нет прав доступа;
  • Запрещено использовать приложение для нарушения правил Google Workspace и применимого законодательства;
  • Автоматические действия (изменение таблиц и документов) выполняются только в рамках задач, поставленных владельцем.

4. Ответственность

Приложение предоставляется «как есть». Владелец самостоятельно контролирует выдаваемые разрешения и может отозвать их в любой момент в настройках Google-аккаунта.

5. Изменения условий

Условия могут обновляться; актуальная версия всегда доступна на этой странице.
