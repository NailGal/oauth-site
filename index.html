О приложении Hermes Google Workspace

Это личное вспомогательное приложение владельца аккаунта. Оно подключается к Google API (Google Sheets, Drive, Docs, Calendar) для автоматизации рабочих процессов: ведение контент-таблиц, публикационных расписаний и внутреннего планирования.

Приложение работает только с аккаунтом владельца и не принимает доступ от других пользователей.
